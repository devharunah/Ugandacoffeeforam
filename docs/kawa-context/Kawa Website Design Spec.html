What this is

Kawa is positioned as a company building digital solutions for coffee farmers and agriculture — not a coffee marketplace. The marketplace is now one solution among several; KawaScan is the flagship app. The site must read as a confident software brand: bold display type, high-contrast bands, one disciplined green, and product shown through faithful phone mockups.

How to use this doc.

Every component below is rendered with the real kawasite.css, so what you see is what ships. When extending the site, copy these patterns and tokens rather than inventing new ones.

01

Component provenance — the anti-generic rule

To stop the UI drifting into generic, arbitrary "AI-looking" components, every component is modeled on a documented pattern from one of two open UI libraries, then re-skinned in Kawa tokens. We adopt structure and interaction patterns only — never any company's proprietary branding, fonts, icons, or assets, and we never clone a product.

Sanity UI
Flat & editorial

Flat surfaces, hairline 1px borders, restrained neutrals, generous whitespace, monospace micro-labels. Drives: solution cards, FAQ, footer, section scaffolding, eyebrows.

Material You
Tonal & pill

Pill / full-radius buttons, tonal (tinted) containers, 13–16px container radius, lifted FAB. Drives: all buttons, the tonal lead card, badges, rounded stage panels, the phone's camera key.

Enforcement rules

  • A new component must map to a pattern in Sanity UI or Material You. If it maps to neither, don't invent — compose from existing patterns.
  • Re-skin only: structure/behavior from the library; color, radius, type, spacing from Kawa tokens.
  • One governing library per component — never blend the two inside a single element.
  • No third-party brand assets. Icons are Kawa's own line set; the only font is Inter.
02

Principles

01
Bold, high-contrast

Alternating white and near-black #0E1311 bands. Big, tightly-tracked Inter display type is the primary brand device.

02
One disciplined green

The same #15683C as the app. Accent only — actions, links, the lead card. On dark, switch to --accent-bright.

03
Flat, hairline-defined

No drop shadows on content. Cards, FAQ and bands separate via hairlines and tint. Only device bezels carry shadow.

04
Product shown natively

KawaScan appears as faithful CSS phone mockups, not screenshots — crisp at any zoom, one language with the app.

Bands

  • Dark reposition band — the mission statement on --dark; big statement with an --accent-bright highlight + 3 mono-numbered columns.
  • Field photo banner — full-width <image-slot> (user-fillable) with a bottom gradient scrim and overlaid statement. The one large photographic moment; overlay is pointer-events:none.
  • CTA band — solid --accent, white type, stacked white / ghost buttons.
  • Footer — --dark; 4-col → 2-col → 1-col, Kawa line icons for socials.

Imagery enters only through <image-slot> placeholders (drag-and-drop, persists). Product is shown via the phone mockup, never screenshots.

Page structure

Narrative order: who we are now → what we build → the flagship → proof + human → how to act → convert.

  • Nav — sticky, blurred, hairline bottom.
  • Hero — 2-col: bold headline + lead + CTAs + trust stats / KawaScan Home phone on a tonal stage.
  • Reposition band (dark) — mission, 3 numbered columns.
  • Solutions — 3 cards; KawaScan tonal lead, Market, Agronomy guide.
  • Flagship spotlight — feature list + two overlapped phones (Home + Pay).
  • Field photo banner — image slot + overlaid statement.
  • How it works — 3 steps (Scan · Diagnose · Act).
  • FAQ — 2-col, flat disclosure list.
  • CTA band (green) → Footer (dark).

Do & don't

Do
  • Map every component to Sanity UI or Material You, re-skinned in tokens.
  • Open each section with the mono eyebrow + rule.
  • Keep one tonal (green) card per grid, as the lead.
  • Alternate white and dark bands for contrast rhythm.
  • Use --accent-bright for green on dark.
  • Show the product via the phone mockup.
Don't
  • Invent a component that maps to neither library.
  • Hard-code hex in component CSS — use tokens.
  • Use --accent as text on the dark band.
  • Put drop shadows on cards, FAQ, or bands.
  • Reintroduce "coffee marketplace" as the headline identity.
  • Pull in third-party brand assets, icons, or fonts.
